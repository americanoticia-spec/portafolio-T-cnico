# Portafolio Web Profesional | Gerardo Colmenares

Este es el repositorio oficial del portafolio web de Gerardo Colmenares, especialista en tecnología y desarrollo digital.

## Características
- Diseño moderno, elegante y oscuro (Dark Mode).
- Desarrollado con HTML5, CSS3 Vainilla y JavaScript.
- Animaciones fluidas al hacer scroll (Intersection Observer).
- **Gestor de Contenidos:** Integración con Sveltia CMS para editar textos e imágenes sin tocar código.

## Enlaces Importantes
- **Sitio Web en Vivo:** [https://americanoticia.github.io/portafolio-T-cnico/](https://americanoticia.github.io/portafolio-T-cnico/)
- **Panel de Administrador:** [https://americanoticia.github.io/portafolio-T-cnico/admin/](https://americanoticia.github.io/portafolio-T-cnico/admin/)

## ¿Cómo editar la página web?
1. Entra al enlace del Panel de Administrador de arriba.
2. Haz clic en "Login with GitHub" e inicia sesión con tu cuenta `americanoticia`.
3. Navega a la colección "Textos y Proyectos".
4. Edita el texto, sube fotos y dale al botón de guardar.
5. GitHub Pages actualizará la página web en los próximos minutos.
